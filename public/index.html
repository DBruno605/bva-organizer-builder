4Connect Canvas and share

Paste the assignment's link so student work turns in to the right place.

  1. In Canvas, set the assignment's submission type to File Uploads (allow .docx).
  2. Paste the same student link into each assignment's description. Each student's work goes to the assignment in their own course.
  3. Students fill it in, click Turn in to Canvas, and get a copy by email.
